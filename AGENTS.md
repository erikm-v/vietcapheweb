# VietCaPhe website

Astro 7 static site (React islands, Tailwind 4, MDX), deployed to GitHub Pages on push to `main`.

- Homepage sections: `src/sections/`. Blog posts: `src/content/blog/*.mdx`. Blog graphics: `src/components/blog/`.
- VietCaPhe sells green (unroasted) specialty robusta to roasters only. Never imply roasted coffee or café supply.
- Writing or planning a blog post: follow `.cursor/rules/blog-posts.mdc` and `docs/blog/PLAYBOOK.md`.
- Verify with `npm run build`, then check the page in the browser on desktop and mobile.
